Политика конфиденциальности

Telegram-бот Guala Parser (@gualaparser_bot)
Редакция от 31 октября 2026 г.

Эта Политика объясняет, какие данные получает бот Guala Parser, зачем они нужны, как хранятся и кому могут передаваться. Бот получает только то, что нужно для его работы: данные Telegram-аккаунта, введённые вами настройки, историю работы в боте и статус платежей. Данные банковских карт и кошельков бот не получает. Продолжая пользоваться ботом, вы соглашаетесь с этой Политикой.

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты информации, которую Пользователь передаёт при использовании Telegram-бота Guala Parser (@gualaparser_bot) (далее — «Сервис»).

1.2. Сервисом управляет его администрация (далее — «Администрация»).

1.3. Используя Сервис, Пользователь подтверждает согласие с условиями Политики. Если Пользователь не согласен с ними, он должен прекратить использование Сервиса.

2. Какие данные получает Сервис

2.1. Данные Telegram-аккаунта, которые Telegram передаёт боту при обращении к нему: Telegram ID, имя пользователя (username), имя и фамилия из профиля.

2.2. Данные, которые Пользователь вводит сам: каналы и ссылки для анализа, никнеймы для поиска по базе, настройки фильтров, тексты рассылок, адреса прокси-серверов.

2.3. Если Пользователь подключает к Сервису свой аккаунт Telegram для рассылки — номер телефона этого аккаунта и ключ сессии. Код подтверждения и пароль двухэтапной проверки используются только для входа и не сохраняются.

2.4. История работы в Сервисе: анализы и их отчёты, найденные каналы, рассылки, доступ, пакеты каналов, баланс, покупки и начисления по реферальной программе.

2.5. Сведения о платежах: сумма, способ оплаты, дата и статус. Оплата проходит на стороне платёжного провайдера. Сервис не получает и не хранит данные банковских карт, банковских счетов и криптовалютных кошельков.

2.6. Технические журналы работы Сервиса: время действий в боте и сведения об ошибках.

2.7. Сервис не запрашивает паспортные данные, документы, фотографии и другую личную информацию, кроме минимально необходимой для работы.

3. Зачем используются данные

3.1. Сервис использует данные только для того, чтобы:

  • выполнять функции Сервиса: анализ, поиск по базе, отчёты и рассылки;
  • учитывать доступ, пакеты каналов, баланс и реферальные начисления;
  • присылать Пользователю уведомления: о готовности отчёта, окончании доступа, зачислении средств;
  • отвечать на обращения в поддержку;
  • защищать Сервис от злоупотреблений и улучшать его работу.

4. Данные из открытых источников

4.1. Сервис анализирует общедоступную информацию Telegram: открытые каналы, публикации, комментарии и публичные профили — и показывает Пользователю результаты в отчёте.

4.2. Сервис не получает доступа к личной переписке Пользователя и других людей.

4.3. Пользователь самостоятельно отвечает за то, как использует данные из отчётов, и обязуется соблюдать законодательство и правила Telegram.

5. Передача данных третьим лицам

5.1. Администрация не продаёт и не передаёт данные Пользователя третьим лицам, кроме случаев, когда:

  • это нужно для проведения платежа (платёжному провайдеру — в объёме, необходимом для оплаты);
  • этого требует закон;
  • Пользователь сам дал на это согласие.

6. Хранение и защита данных

6.1. Данные хранятся, пока Пользователь пользуется Сервисом, и в течение срока, необходимого для учёта платежей и разбора обращений.

6.2. Ключи сессий подключённых аккаунтов хранятся в зашифрованном виде. Пользователь может в любой момент отключить аккаунт в профиле бота — ключ сессии будет удалён. Завершить сессию можно и в самом Telegram: «Настройки» → «Устройства».

6.3. Администрация принимает разумные меры для защиты данных, но не гарантирует абсолютную безопасность информации при передаче через интернет.

7. Права Пользователя

7.1. Пользователь может узнать, какие его данные хранятся в Сервисе, и попросить их удалить, написав в поддержку.

7.2. После удаления данных восстановить историю, доступ, пакеты каналов и баланс будет нельзя.

8. Отказ от ответственности

8.1. Пользователь понимает, что передача информации через интернет всегда связана с рисками.

8.2. Администрация не несёт ответственности за утрату, кражу или раскрытие данных, если это произошло по вине третьих лиц или самого Пользователя.

9. Изменения Политики

9.1. Администрация вправе изменять Политику. Актуальная редакция всегда доступна в боте, в разделе «Документы».

9.2. Продолжение использования Сервиса после изменений означает согласие Пользователя с новой редакцией.
